# Vrinda Store — Sales Analysis (Excel) 📊

An Excel-based data analysis project exploring annual sales performance for **Vrinda Store**, using pivot tables, charts, and slicers to build an interactive dashboard.

> ⚠️ **Note:** The workbook file in this repo currently appears empty/corrupted on GitHub. Please re-upload the `.xlsx` file — GitHub sometimes fails silently on binary file uploads via the web UI. Drag-and-drop or `git add`/`git push` from the command line is more reliable for Excel files.

## 📌 Objective

Vrinda Store wants an annual sales report to better understand its customers and identify opportunities to grow sales going forward. This project cleans, analyzes, and visualizes the raw sales data to answer key business questions such as:

- How do sales and orders trend together over the year?
- Which months see the highest sales activity?
- What's the relationship between customer age, gender, and purchasing behavior?
- Which states contribute the most to overall sales?
- Which sales channels (e.g. Amazon, Flipkart, Myntra) drive the most revenue?
- What is the order fulfillment / delivery status breakdown?

## 🧹 Data Cleaning

- Removed duplicate entries and null/missing values
- Standardized data types and formats across columns
- Verified consistency in categorical fields (state, channel, category, etc.)
