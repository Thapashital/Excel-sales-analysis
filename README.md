# HR Analytics Dashboard 📊

An interactive **Power BI** dashboard that analyzes employee attrition and workforce trends using HR data. Built as a single-page report (`HRA.pbix`), it helps HR teams and analysts quickly identify *who* is leaving, *why*, and *where* attrition risk is highest.

## Overview

The dashboard is powered by an `HR_Analytics` dataset and combines KPI cards, charts, and a pivot table to give a 360° view of employee attrition patterns.

## Key Metrics (KPI Cards)

- Total Employees
- Attrition Count
- Attrition Rate
- Average Age
- Average Monthly Income
- Average Years at Company

## Visuals Included

| Visual | Insight |
|---|---|
| 🍩 Donut Chart | Attrition rate by **Education Field** |
| 📊 Column Chart | Attrition count by **Age Group** |
| 📋 Pivot Table | Attrition count by **Job Role** vs. **Job Satisfaction** |
| 📊 Bar Chart | Attrition count by **Salary Slab** |
| 📊 Bar Chart | Attrition count by **Job Role** |
| 📈 Area Chart | Attrition trend by **Years at Company** |
| 🌳 Treemap | Attrition count by **Gender** |
| 🎛️ Slicer | Filter the entire dashboard by **Department** |

## Tech Stack

- **Power BI Desktop** — data modeling, DAX measures, and visualization

## How to Use

1. Download `HRA.pbix`.
2. Open it in [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free).
3. Use the Department slicer to filter results, and hover over visuals for detailed tooltips.

## Purpose

This dashboard is designed to support HR decision-making by surfacing attrition drivers — such as job satisfaction, salary band, tenure, and demographics — in a single, interactive view.
